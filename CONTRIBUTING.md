# Contributing

Thank you for helping improve Clearer’s documentation.

## Guidelines

- **Use Markdown.** Write documentation as plain Markdown (or MDX only when necessary).
- **Use British English.** Prefer British spelling and phrasing (e.g. organise, favour, behaviour).
- **Explain “why” before “how”.** Start with the reason or principle, then describe the steps or details.
- **Keep documentation concise.** Prefer short pages, clear headings, and only the detail a reader needs.
